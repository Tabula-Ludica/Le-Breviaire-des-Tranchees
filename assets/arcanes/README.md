# Visuels des arcanes

Déposez ici les illustrations des 22 cartes. Le site les affiche automatiquement dans la galerie du chapitre IV.

## Nommage

Un fichier par carte, nommé par son numéro sur **deux chiffres** :

| Fichier | Carte | Fichier | Carte |
|---|---|---|---|
| `00` | Le Mat | `11` | La Force |
| `01` | Le Bateleur | `12` | Le Pendu |
| `02` | La Papesse | `13` | La Mort |
| `03` | L'Impératrice | `14` | Tempérance |
| `04` | L'Empereur | `15` | Le Diable |
| `05` | Le Pape | `16` | La Tour |
| `06` | L'Amoureux | `17` | L'Étoile |
| `07` | Le Chariot | `18` | La Lune |
| `08` | La Justice | `19` | Le Soleil |
| `09` | L'Ermite | `20` | Le Jugement |
| `10` | La Roue de Fortune | `21` | Le Monde |

Formats acceptés, dans cet ordre de priorité : **`.webp`**, `.png`, `.jpg` (par exemple `15.webp` pour Le Diable).

## Format conseillé

- **Proportions 7 × 12** (format tarot), par exemple **700 × 1200 px**.
- L'image est recadrée pour remplir la carte : gardez le sujet au centre.
- Visez moins de 300 Ko par carte (le `.webp` aide beaucoup).

Tant qu'un visuel manque, le site affiche une carte de remplacement avec le numéro et le nom.
