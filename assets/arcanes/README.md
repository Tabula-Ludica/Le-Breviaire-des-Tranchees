# Visuels des arcanes

Déposez ici les illustrations des 22 cartes. Le site les affiche automatiquement dans la galerie du chapitre IV.

## Nommage

Un fichier par carte, numéroté de **01 à 22** :

| Fichier | Carte | Fichier | Carte |
|---|---|---|---|
| `01` | Le Mat | `12` | La Force |
| `02` | Le Bateleur | `13` | Le Pendu |
| `03` | La Papesse | `14` | La Mort |
| `04` | L'Impératrice | `15` | Tempérance |
| `05` | L'Empereur | `16` | Le Diable |
| `06` | Le Pape | `17` | La Tour |
| `07` | L'Amoureux | `18` | L'Étoile |
| `08` | Le Chariot | `19` | La Lune |
| `09` | La Justice | `20` | Le Soleil |
| `10` | L'Ermite | `21` | Le Jugement |
| `11` | La Roue de Fortune | `22` | Le Monde |

Formats acceptés, dans cet ordre de priorité : **`.webp`**, `.png`, `.jpg` (par exemple `16.webp` pour Le Diable). Le numéro du fichier est le même que celui affiché sur la carte.

## Format conseillé

- **Proportions 7 × 12** (format tarot), par exemple **700 × 1200 px**.
- L'image est recadrée pour remplir la carte : gardez le sujet au centre.
- Visez moins de 300 Ko par carte (le `.webp` aide beaucoup).

Tant qu'un visuel manque, le site affiche une carte de remplacement avec le numéro et le nom.
